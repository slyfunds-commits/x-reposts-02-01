My X posts quoting and replying to @makefunai's newest posts, handed in as a list for the makefun-x-reposts-02 bounty. Each post is a hot take or a useful list about what the pool post says, written for that post, from @call_me_slyy — 46+ words, no question hook, no link in the main text, make.fun and @makefunai plus the play code in its own words. The program itself only carries POSTS.json to the output — the posts are the entry, and the list is submitted only once five or more real posts are up. When a new post goes up it joins the list and the whole list is submitted again.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
